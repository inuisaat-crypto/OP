# OP — Pybricks

## Меню хаба

На главном экране две плитки: верхняя — «Миссии», нижняя — «Тесты».
LEFT выбирает верхнюю плитку, RIGHT — нижнюю, CENTER открывает раздел.
В списке миссий или тестов LEFT/RIGHT переключает пункт; LEFT+RIGHT
возвращает в меню разделов. На главном экране LEFT+RIGHT завершает программу.

В миссиях архива лежат `mission_1.py`–`mission_4.py`. Тест выполняет квадрат
со стороной 200 мм и четырьмя поворотами по 90°, затем по очереди проверяет
моторы навесок на портах E и F коротким движением туда и обратно и подаёт
звуковой сигнал. Перед запуском теста освободите вокруг робота место для
квадрата.

Каталог `mission_catalog.py` использует статические импорты: при добавлении
обычного Python-модуля его нужно внести в соответствующий список каталога.
JSON-миссии добавляются в архивный каталог автоматически.

## Архив проекта

Запустите `python build_archive.py`. Скрипт создаст файл
`missions/OP_pybricks_project.zip` только с Python-файлами для Pybricks Code.
Скрипт проверит каждый `missions/mission_*.json`, сгенерирует из него одноимённый
`.py` и добавит новую миссию в каталог архива. При совпадении имён JSON-рецепт
используется вместо одноимённого исходного `.py` внутри архива. Сам JSON в ZIP
не попадает. Распакуйте архив в один проект и запустите `main.py`.

## Флаги отладки и калибровка

В `core.py` три флага: `DEBUG_LOG` (журнал движений), `DEBUG_BEEP` (служебные
писки: `beep()`, предупреждение о батарее, сигнал ошибки движения) и `DEBUG_RAISE`
(пробрасывать исключение миссии в меню с полным traceback). На соревнованиях
`DEBUG_LOG = DEBUG_BEEP = False`: каждый `print` и `beep` стоит времени, а меню
всё равно ловит любую ошибку миссии, гасит моторы и возвращает управление.

Сводка калибровки — `calibration_report()`: диаметр колеса и колея, поправка
гироскопа, профили `FAST`/`MEDIUM`/`SLOW`/`SLOWW`, параметры `rush()` и стыков.

## JSON-миссии: проверка в терминале

Запусти `mission_tester.py` из отдельного Bluetooth-окружения:

Тестер автоматически подключается к первому найденному включённому Pybricks-хабу
и показывает список `missions/mission_*.json`. Выбор миссии сразу запускает её без
дополнительного подтверждения. Во время движения нажми `Q` (или `Esc`), чтобы
остановить миссию. После завершения или остановки выбери `1`, чтобы перезапустить
эту миссию, либо `2`, чтобы вернуться к списку. Подключение сохраняется, пока
не нажмёшь `q` в списке миссий. Кнопка CENTER на хабе также служит физическим
стопом. Если передача программы не удалась, тестер оставит сессию открытой и
предложит повторить загрузку либо вернуться к списку, если Bluetooth-соединение
ещё активно. Тестер следит за выбранным JSON и замечает его изменения во время
работы; текущий запуск не прерывается, а новая версия автоматически
перечитывается при выборе перезапуска.

Для Bluetooth установи Python 3.10+ и создай отдельное окружение в корне
проекта. PybricksDev и его зависимости останутся в `.venv-mission-tester` и не
будут установлены в общий Python:

```powershell
py -3 -m venv .venv-mission-tester
.\.venv-mission-tester\Scripts\python.exe -m pip install -r requirements-mission-tester.txt
.\.venv-mission-tester\Scripts\python.exe mission_tester.py
```

Для следующих Bluetooth-запусков достаточно последней команды. Офлайн dry-run
запускается отдельно: `python mission_tester.py --offline`. Перед запуском
освободи пространство вокруг робота и отключи хаб от Pybricks Code или других
Bluetooth-приложений. Описание JSON — в
[JSON_GUIDE.md](./JSON_GUIDE.md).

## Блочный редактор миссий

Установи Node.js и npm, затем из папки `mission_editor` выполни `npm install`
и `npm run dev`. Редактор откроется по адресу, который покажет Vite
(обычно `http://127.0.0.1:5173`). Рецепты лежат в `missions/`, туда же
собирается `OP_pybricks_project.zip`.

В шапке только «OP», меню «Файл», «Отменить/Повторить», меню «Вид» и настройки.
«Открыть» показывает список миссий из `missions/`, «Сохранить» пишет текущую
миссию (для новой сначала спрашивает номер), «Собрать» запускает
`build_archive.py`, «Создать» делает пустую миссию белого цвета, «Редактировать
миссию» меняет название, номер и цвет.

Меню «Вид» сворачивает панели, разворачивает карту на весь экран и запускает
предпросмотр. В настройках — скорость предпросмотра, разгон и торможение в
мм/с² и °/с², показ плана маршрута и пройденного следа, автосохранение.
Горячие клавиши: Ctrl+S — сохранить, Ctrl+B — собрать, Ctrl+P — предпросмотр.

Панель блоков сворачивается кнопкой «‹» до цветных полос категорий, карта —
кнопкой «›» в правом верхнем углу. Блоки разложены по группам: «Движение» —
прямо, поворот, поворот на курс, пивот вокруг колеса, дуга и прижатие к стене;
«Навески» — поворот на угол, до упора и ускорение; «Действия» — пауза, сигнал,
лог и проверка батареи; «Робот» — профиль скорости, опорный курс, быстрый
режим, стоп и сброс на старт; «Логика» — условие, повтор, параллельные каналы
и сравнение датчика. Под картой — стартовая поза робота. Кнопка
воспроизведения проигрывает маршрут с разгоном и торможением, полоса под картой
перематывает, а кнопка в правом нижнем углу карты разворачивает её на весь
экран. Для параллельного блока можно запускать вместе привод и независимые
навески E/F. Карта использует масштаб PDF (шаг сетки 20 см): примерно
200 × 114 см, контур робота 183 × 120 мм и начальную точку в центре корпуса.
Предпросмотр не моделирует проскальзывание колёс. У движений есть переключатель
«стоп / на проход»: «на проход» превращается в `through` и `then=Stop.NONE` в
сгенерированном коде.
